Kanso Studio

**Minimalist coding studio for 17 languages.**

Kanso Studio is an interactive coding playground designed for speed and simplicity. Explore supported languages, load curated code snippets, and launch a dedicated workspace to write, execute, and save your code locally with multi-language tab support.

---

## ✨ Key Features

* **17 Supported Languages:** Write and run code across 4 distinct categories—Systems, Scripting, Web & Mobile, and Data & Query—complete with interactive 3D language panels and instant filtering.
* **Live Code Execution:** Run programs immediately inside the dedicated workspace, including an in-memory SQLite engine with structured table grids for SQL queries.
* **Compatible Multi-Language Tabs:** Work seamlessly across paired environments in a single session:
  * `Python + SQL`
  * `JavaScript + TypeScript + SQL`
  * `C + C++`
  * `Java + Kotlin`
* **Curated Code Snippets:** Jumpstart your coding by opening pre-loaded examples directly in the workspace editor.
* **Local File Management:** Save your scripts directly to your local Files library for quick access later.
* **Customizable UI:** Toggle between crisp **White** and **Obsidian (Dark)** themes, and enable or disable the custom **Coding Cursor**.
* **Keyboard-First Workflow:** Built-in hotkeys allow you to navigate, switch languages, save, and run code without leaving your keyboard.

## ⌨️ Keyboard Shortcuts

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| `⌘ / Ctrl + Enter` | **Execute active program** | Runs code immediately from anywhere in the workspace. |
| `⌘ / Ctrl + S` | **Save current file** | Stores your code into the local Files library. |
| `⌘ / Ctrl + K` | **Open language matrix** | Search and switch across all 17 supported languages. |
| `⌘ / Ctrl + J` | **Switch light / dark theme** | Alternates between crisp white and obsidian modes. |
